# 漫界 MangaVerse

![App Icon](metadata/en-US/icon.png)

漫界 MangaVerse 是一款面向中文用户的现代化漫画阅读 App，聚合多个内容源路线的漫画更新，提供统一的浏览、搜索、阅读与收藏体验。简洁的 Netflix 风格界面、智能聚合去重、图像增强与沉浸式阅读，让追漫更高效。

## 核心特性

- **一号/二号路线聚合**：内置多个数据源路线，自动聚合各源更新，重复内容智能去重，优先展示更新最快最完整的版本
- **原创内容**：服务器收录原创漫画内容，App 内可直接发现与阅读
- **沉浸式阅读**：支持上下滚动、右左翻页与条漫模式，进入阅读自动保持屏幕常亮
- **图像增强**：可选本地图像增强处理，提升低清晰度图片的阅读体验
- **智能推荐**：基于阅读历史的个性化推荐内容
- **多主题**：内置多种主题方案，随时切换阅读氛围
- **任务广场**：每日任务与权益体系，解锁全免阅读时长

## 开始使用

1. 安装后首次启动进入引导向导，完成核心依赖下载与阅读偏好设置
2. 在主界面选择内容路线，浏览聚合更新
3. 收藏喜欢的漫画，保持追更记录
